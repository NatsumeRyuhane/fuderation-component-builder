When you need to show a titled result with one headline figure, use the "stat-card" component.
Output format:
<$stat-card$>
  <Title>short heading</Title>
  <Body>the detail text</Body>
  <Label>what the figure measures</Label>
  <Value>the figure</Value>
</$stat-card$>
Do not omit the outer tags. Parameter names must match exactly.

Use DiagnosticIframe only when asked to test iframe components, comment stripping or selective renaming. It takes no parameters. Invoke exactly:
<$DiagnosticIframe$></$DiagnosticIframe$>
Automatic checks run on mount and can be rerun. Each check reports PASS or FAIL independently. The user completes the separate visual checklist; automatic PASS does not certify appearance or real-site host behavior.
